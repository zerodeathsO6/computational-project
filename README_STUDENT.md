# Schedule Maker v2 - Student Guide

This is a simple schedule/tournament maker designed using basic python programming.

## What this program does
- Creates and manages tournaments (sports leagues, etc.)
- Generates round robin fixtures (every team plays every other team once)
- Keeps track of results and displays a league table with standings
- Can save and load tournaments

## How to run it
```bash
python3 mn.py
```

## Files explained
1. mn.py - Main program that controls everything
2. utils.py - Helper functions for getting input from user
3. writer.py - Saves and loads data to/from files
4. format.py - Makes output look nice
5. tournament.py - Handles round robin scheduling and tables
6. pages/*.py - Different screens/menus in the app

## Basic Python concepts used
- Variables, lists, loops (while/for), if statements, functions
- Reading/writing files with CSV
- Importing modules
